Algorithm Comparison
Why Two Algorithms?
Dijkstra Algorithm
Uses a min-heap priority queue. Always expands the lowest-cost node first. Cannot handle negative weights. Optimal for this network with complexity O((V+E)logV).
Bellman-Ford Algorithm
Relaxes all edges V-1 times. Slower but handles negative weights and detects negative cycles. Used to validate Dijkstra results with complexity O(VxE).
Conclusion
Both algorithms produce identical results. Dijkstra is preferred for production due to better time complexity.
