# Lab Requirements

## Network Simulation Platform
- PNetLab (Enterprise network emulation)

## Cisco Device Images Used
The following Cisco IOL images are used for network simulation:

- **L2-ADVENTERPRISEK9-M-15.2-IRON-20151103.bin**
  Used for Layer 2 switching (Access / Distribution)

- **L3-ADVENTERPRISEK9-M-15.2-M5.3.bin**
  Used for Layer 3 routing (Core Layer)
